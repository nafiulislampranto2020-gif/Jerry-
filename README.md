# Proposal Webpage for Zariya 💍❤️

An interactive, romantic proposal website created with HTML5, CSS3 (Glassmorphism & animations), and JavaScript.

## ✨ Features
- **Romantic Aesthetic:** Soft pink gradient, floating canvas hearts, ambient glow, and Google Fonts.
- **Cute Character:** Cute animated Milk & Mocha bears asking the big question.
- **Playful "No" Button:** Runs away and evades the cursor/touch with funny teasing lines ("Error 404: No not found!", "You can't escape my love!").
- **Dynamic "Yes" Button:** Grows bigger with every failed attempt to click "No".
- **Grand Celebration:** Confetti explosion, hugging bear animation, romantic love letter, and audio chimes.
- **Zero Broken Audio Dependency:** Romantic melody synthesizer powered by Web Audio API.

## 🚀 How to Host on Vercel

### Option 1: Using Terminal (Fastest)
1. Open PowerShell or Terminal in this folder (`c:\Users\Napro\OneDrive\Desktop\Jerry`).
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the quick prompts (Log in with GitHub/Email if prompted).
4. Within 15 seconds, your live link (e.g. `https://proposal-zariya.vercel.app`) will be ready!

### Option 2: Via GitHub + Vercel
1. Create a repository on GitHub and push these files.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository and click **Deploy**.
